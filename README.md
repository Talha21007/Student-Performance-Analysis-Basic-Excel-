Project Overview
This project involves the creation of a Student Performance Tracker using Microsoft Excel. The goal was to practice data organization and apply core mathematical functions to evaluate academic results efficiently. This project serves as a foundation for data analysis, focusing on row-level and column-level calculations.

🛠️ Functions & Techniques Applied
I utilized the following Excel functions to process the student data:

SUM (Total Score): - Used to aggregate marks from multiple subjects for each individual student.

Formula: =SUM(C2:E2)

AVERAGE (Mean Performance): - Calculated the average score per student to provide a standardized metric of their overall performance.

Formula: =AVERAGE(C2:E2)

MIN & MAX (Statistical Extremes): - Identified the lowest and highest marks achieved by each student to highlight strengths and areas for improvement.

Formula: =MIN(C2:E2) and =MAX(C2:E2)

Column Aggregation: - Calculated the total marks for the entire class per subject to understand subject-wise difficulty and performance trends.

📊 Dataset Structure
The project contains the following data points:

Student Information: Name and Serial Number.

Raw Data: Scores for three different subjects.

Analytical Metrics: Total, Minimum, Maximum, and Average.
